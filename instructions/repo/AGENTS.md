# Repository guide

- This is an established Python project. Inspect nearby implementation and existing tests before editing.
- Preserve compatibility with the checked-out version and follow the style already used in affected files.
- Prefer the smallest root-cause correction over an issue-specific workaround.
- Keep unrelated behavior unchanged. Do not update dependencies, rewrite history, or perform broad formatting.
- Leave only the intended source and directly relevant regression-test changes in the working tree.
